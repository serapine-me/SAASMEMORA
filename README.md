# Creator OS AI

Production-ready SaaS foundation using Next.js App Router + TypeScript + Tailwind + Supabase + OpenAI.

## Architecture

- `app/`: App Router pages, route groups, and API routes.
- `components/`: shared UI and domain components.
- `lib/`: service clients, helpers, business logic modules.
- `types/`: domain-level type definitions.
- `supabase/migrations/`: SQL migrations.
- `styles/`: style tokens and future design system assets.
